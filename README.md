# 慢递愿望局 · Pocket Pause

把“现在就买”寄给明天的自己：冷静期愿望清单、消费复盘和独立的手动存入日记。

```bash
npm run dev
# http://127.0.0.1:4181
npm test
npm run check
npm run build
```

Node 22+ 只用于测试、构建和本地服务，无需安装依赖。生成的 `dist/` 是静态网页；ES module 需通过 HTTP 打开。运行不请求外网、不连接支付账户、不执行金融操作。

## 完整工作流

1. 寄存一个愿望，填写金额并选择 1 / 24 / 72 小时冷静期。
2. 到时给自己回信：仍然喜欢就决定买下，或者放下；可以留一句复盘。
3. “放下的消费意向”不会自动变成存款。自行完成存入后，可以另记一笔手动日记，标注未经账户核验。
4. 同一愿望可分次关联记录，但累计不超过原金额；误记支持撤销并保留更正轨迹。
5. 自选目标、导出/导入完整备份。浏览器存储受限时仍可在当前页运行，并提示导出。

“演示小店”含虚构的保鲜中、待回信和已放下案例。替换现有记录前会明确提示备份。金额使用整数分；存档通过有界事件重放校验。

## 别人做过什么，实际借用了什么

愿望清单、冷静期和存款目标都有成熟先例；本项目不宣称全新发明。[对比报告](docs/landscape.md) 评估 Actual Budget、wishthis 与 idb-keyval，说明现有能力、场景差异及准确许可证。

实际复用 **idb-keyval 6.3.0（Apache-2.0）**，固定 npm 发布包、校验完整性，随项目分发原始署名和完整许可证；它在运行时不从 CDN 下载。其余应用逻辑与界面为独立实现。[第三方通知](THIRD_PARTY_NOTICES.md) 包含文件来源与哈希。原生功能与故障回退由 17 项行为测试覆盖。
