# Xiaohobao AI Plugin Creator Contest — status and delivery boundary

Source: the official 支付宝小荷包 account's [public announcement](https://www.xiaohongshu.com/discovery/item/6a96b088000000001103af07),
read in the rendered browser on 2026-11-04. The post invites savings, spending,
and collaborative plugin concepts. Its pinned author comment sets the activity
closing date to **October 31**. The linked activity is therefore already closed
as of this project's creation on November 4, 2026. No later reopening or extension
was verified; this repository must not be advertised as an entry in an open contest.

The project supplies a reusable working browser prototype and an original
[creator prompt](../creator-pack/xiaohobao-prompt.txt). Public SDK fields, automatic
save/reminder hooks, and a deployable third-party-plugin manifest were not verified.
The prompt is a candidate to copy into the actual creation interface, not an
invented official deployment package. Real Alipay creation, platform capabilities,
account terms, review and any future activity requirements must be checked in the
user's authorized platform session. No account was connected or contest submitted.

The app makes no transfers or purchases, triggers no friend penalties, and does
not verify balances. It records decisions and explicitly user-reported deposits
in separate ledgers. Demo examples are fictional. External account statements,
identifiers and authentication data are not requested or included.
